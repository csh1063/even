moa — 디자인 테마 전체 정리

마케팅용 moa_design_spec.html과 달리, 이 문서는 실제 소스 코드(Assets.xcassets, Extension_UIColor/UIFont, Presentation 컴포넌트 전체)를 다시 훑어 색상·타이포·스페이싱·라운드·그림자·컴포넌트를 빠짐없이 검증한 디자인 시스템 레퍼런스입니다. 스크린샷 없이 토큰과 컴포넌트 카탈로그에 집중합니다.

Colors

18 tokens

원본은 Projects/Presentation/Resources/Assets.xcassets/color/*.colorset이며, Extension_UIColor.swift의 enum Theme이 각 토큰을 Theme.primary처럼 static 프로퍼티로 노출합니다. 별도 Spacing/Radius enum과 달리 색상만은 유일하게 중앙화된 토큰입니다.

Typography

시스템 폰트 · 12 steps
확인됨
커스텀 폰트 없음. Extension_UIFont.swift에 Pretendard 계열 로더 함수(boldLocalizedFont 등)가 있지만 실제 매핑 코드는 주석 처리된 죽은 코드이며, 번들에 .ttf/.otf 파일도 없고 Info.plist에 UIAppFonts 등록도 없습니다. 결과적으로 전 화면이 시스템 폰트(SF Pro · 한글은 Apple SD Gothic Neo)로 렌더링됩니다. 별도 타입스케일 enum도 없이 화면마다 UIFont.systemFont(ofSize:weight:)를 직접 호출합니다.

Spacing

비공식 스케일 · 7 steps

전용 Spacing/Metric enum은 존재하지 않습니다(검색 결과 0건). SnapKit 제약과 UIStackView.spacing에 하드코딩된 값들을 모아 보면 대략 4/6/8/12/16/20/24pt의 비공식 스케일로 수렴합니다.

Corner Radius

18 measured values

전용 Radius enum 없이 컴포넌트별 layer.cornerRadius 리터럴이 흩어져 있습니다. 재사용 헬퍼로 UIView/UIButton.withLayerCornerRadius(_:)가 있지만 값 자체는 자유롭게 넘겨받습니다.

Sheet Chrome Radius — 28pt 바텀시트 6종 전부가 UISheetPresentationController.preferredCornerRadius = 28을 공유합니다. 콘텐츠 뷰의 개별 cornerRadius와는 별개로, 시스템이 그리는 시트 외곽 라운드값입니다. (TabbarCoordinator.swift, AlbumDetailCoordinator.swift ×5, TravelerManagementSheet.swift)

Shadow Presets

4 static + 1 animated

Extension_UIView.swift의 addShadow(color:opacity:offset:radius:) / addInnerShadow(...) 헬퍼 기반이며, traitCollection에 맞춰 색을 resolve하므로 라이트/다크 전환 시 그림자 색도 함께 바뀝니다.
